## Ключові архітектурні напрямки

<CardGrid stagger>
  <Card title="NestJS 11 CQRS & PostgreSQL 16" icon="setting">
    Чиста ізоляція бізнес-логіки: 1 хендлер на файл, транзакційний Outbox, BullMQ черги та 100% покриття FK-індексами в Prisma ORM.
  </Card>
  <Card title="Tauri v2 + SQLCipher" icon="laptop">

  </Card>
  <Card title="Обробка 100k+ SKU фідів" icon="rocket">

  </Card>
  <Card title="Двомовність & Безпека" icon="document">
    Повний паритет української та англійської локалізації (`uk`/`en`), 4-рівневий захист (DTO, Quotas, RBAC, DB constraints) та SSRF захист.
  </Card>
