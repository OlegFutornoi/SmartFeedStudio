# ❓ Посібник Користувача: Часті Запитання (FAQ)

## 📌 Загальні Питання

### 1. Що мені потрібно для запуску SmartFeed Studio?

Десктопний додаток є автономним виконуваним файлом для macOS, Windows або Linux. Він автоматично підключається до хмарного API або локального сервера бекенду та не вимагає встановлення сторонніх баз даних на робочому комп'ютері.

### 2. Які формати каталогів підтримуються?

Платформа підтримує:

- **XML / YML**: Стандартизовані фіди для Rozetka, Prom.ua, Hotline, Price.ua.
- **CSV**: Табличні прайс-листи будь-якої структури з розділювачами комами, крапкою з комою або табуляцією.
- **Google Merchant Center XML/CSV**: Фіди для динамічного ремаркетингу та Google Shopping.

### 3. Де зберігаються мої паролі та ключі постачальників?

Усі чутливі токени зберігаються в апаратно захищеному зв'язку ключів вашої операційної системи (Apple Keychain на macOS або Windows Credential Manager на Windows). До них не мають доступу браузери або сторонні програми.

### 4. Чи можу я працювати без доступу до інтернету (Offline)?

Так! Десктопний клієнт зберігає кеш каталогів у локальній зашифрованій базі даних SQLCipher (AES-256). Ви можете переглядати та редагувати товарні позиції офлайн, а синхронізація з хмарою відбудеться при появі інтернет-з'єднання.

### 5. Як змінити мову інтерфейсу або тему оформлення?

- У правому верхньому кутку будь-якої сторінки натисніть кнопку з глобусом (`UA` / `EN`) для миттєвої зміни мови.
- На сторінці **"Налаштування"** (`/settings`) ви можете вибрати колірну схему (`Zinc`, `Slate`, `Stone`, `Bronze`) та перемикач `Dark Mode` / `Light Mode`.

### 6. Що робити, якщо я забув пароль?

На сторінці входу натисніть посилання **"Забули пароль?"**, введіть адресу електронної пошти та отримайте код скидання для встановлення нового паролю.
