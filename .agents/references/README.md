# 📚 SmartFeed Studio — Довідники та Спеціалізовані Ролі Агентів (Agent Reference Playbooks)

> **Розташування:** `.agents/references/`  
> **Призначення:** Повні інженерні плейбуки, 8-етапні регламенти та готові шаблони запитів для профільних агентів проекту.

Цей каталог містить вичерпні інструкції для спеціалізованих інженерних ролей повного циклу.

---

## 🏛 Чому ці файли знаходяться в `references/`

- **Оптимізація контекстного вікна IDE:** В Antigravity IDE будь-який файл `.md`, розташований безпосередньо в корені `.agents/`, автоматично завантажується як системне правило в кожен запит.
- Оскільки детальні плейбуки мають сумарний обсяг ~380KB, їхнє перебування в корені переповнювало ліміт системного промпту і призводило до примусового виключення корисних скілів.
- Розміщення в `references/` дозволяє звертатися до них **за потребою** (on-demand), зберігаючи 100% доступність усіх правил без перевитрати токенів контексту.

## 🎯 Як викликати потрібного агента

### 1. Пряме посилання на плейбук ролі (Рекомендовано для складних задач)

Додайте `@` перед назвою файлу в чаті, щоб агент завантажив повний регламент для виконання завдання:

```text
@agents_backend.md реалізуй CQRS обробник для імпорту товарів постачальника Brain
```

```text
@agents_frontend.md онови дизайн модалки оплат відповідно до правил ui-ux-pro-max
```

```text
@agents_review.md проведи повний аудит останніх змін перед релізом
```

### 2. Виклик за ім'ям ролі або скіла

```text
backend: створи команду оновлення залишків товару
```

```text
frontend: додай сортування в таблицю ліцензій
```

### 3. Використання готового шаблону

Відкрийте [`task_prompt_examples.md`](./task_prompt_examples.md), скопіюйте потрібний блок (наприклад, для нової фічі чи тестування) та підставте свої параметри.
