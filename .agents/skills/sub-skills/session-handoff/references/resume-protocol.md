# Resume Protocol

1. `ls plans/active/*.state.md` — знайти state-файл задачі.
2. Прочитати його повністю (він короткий) і план `<feature_name>.md` лише в потрібних розділах.
3. Не перевіряти повторно пункти «Зроблено», якщо немає ознак регресії; одразу братися за «В процесі».
4. Якщо state-файлу немає — `task-router` → `project-context-map` → створити state-файл після першого етапу.
5. Після кожного завершеного етапу оновити state-файл.
