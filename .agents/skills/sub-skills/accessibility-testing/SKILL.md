# accessibility-testing

Інженерний стандарт тестування доступності (Accessibility / a11y) у SmartFeed Studio: автоматична валідація стандартів WCAG 2.1 Level AA, клавіатурна навігація, пастки фокусу в модальних вікнах та контрастність тексту.

## Залізні принципи доступності

1. **Нуль порушень axe-core (Zero Violations)**: Кожен ключовий екран (каталог, тарифи, авторизація, модальні вікна) зобов'язаний проходити перевірку `@axe-core/playwright` з результатом 0 критичних або серйозних порушень (`violations.length === 0`).
2. **100% Клавіатурна навігація**: Будь-яка дія, доступна за допомогою миші (відкриття модалки, вибір товару, сортування таблиці, видалення фіду), повинна бути доступна виключно з клавіатури (`Tab`, `Shift+Tab`, `Enter`, `Space`, `Escape`).
3. **Пастка фокусу в діалогах (Focus Trap)**: При відкритті діалогового вікна або модалки фокус автоматично переміщується на перший інтерактивний елемент або кнопку закриття і **не може вийти** за межі модалки при натисканні `Tab`. Натискання `Escape` завжди закриває модалку і повертає фокус на елемент виклику.
4. **Обов'язкові `aria-label` для іконок**: Кнопки, що містять лише SVG-іконки (наприклад, кошик видалення, олівець редагування, перемикач мови `UA/EN`), зобов'язані мати атрибут `aria-label={t('...')}`.
5. **Мінімальний контраст (Contrast Ratio ≥ 4.5:1)**: Контрастність тексту до фону повинна відповідати WCAG AA (мінімум 4.5:1 для звичайного тексту та 3:1 для великих заголовків) як у світлій, так і в темній темах.

## Категорично заборонено

- Використовувати кнопки-іконки `<button><TrashIcon /></button>` без описового `aria-label`.
- Вимикати видимий фокус клавіатури (`outline: none` без додавання кастомного `focus-visible:ring`).
- Дозволяти фокусу "гуляти" по сторінці під відкритою модалкою (порушення focus trap).
- Використовувати низькоконтрастний сірий текст на темному або світлому фоні (менше 4.5:1).
