# Шаблон запису

```
| L-NNN | <інваріант одним реченням, що можна перевірити> | <шар/файл> | <тест, lint-правило або пункт чеклиста> |
```

Процедура:

1. `grep` по `registry.md` і `.agents/rules/` — чи вже є.
2. Додати рядок з наступним номером.
3. Створити/оновити перевірку (RED-тест або ESLint-правило).
4. Якщо клас помилки широкий — оформити правило в `.agents/rules/*.md` (<12 000 символів) або підскіл через `skill-creator`.
5. Одним рядком повідомити користувача: «додано L-NNN».
