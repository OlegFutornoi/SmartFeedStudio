# Context Budget — економія токенів без втрати знань

1. **Порядок пошуку**: `wiki/README.md` → профільний `wiki/0X-*` → `grep` по символу → `view_file` з діапазоном рядків. Файл цілком — лише якщо <250 рядків і потрібен увесь.
2. **Логи/тести**: запускати з фільтром (`| tail -n 40`, `--reporter=line`); повний вивід читати лише при падінні.
3. **Не повторювати прочитане**: після першого читання записати у робочу нотатку 3–5 фактів (шлях, сигнатура, інваріант), а не перечитувати.
4. **Паралельні виклики**: незалежні читання/пошуки — одним блоком.
5. **State file для довгих задач**: `plans/active/<task>.state.md` — зроблено / в процесі / відкрито / прийняті рішення / команди перевірки. Оновлювати після кожного етапу; при компакції починати з нього. Формат і протокол — скіл [`session-handoff`](../../session-handoff/SKILL.md).
6. **Рішення не переглядати**: перш ніж пропонувати альтернативу, перевірити `plans/completed/` та `wiki/` — чи вже вирішено.
7. **Відповідь користувачу**: коротко, таблицями; без переказу артефактів.
