# Self-Evolution — коли агент знаходить прогалину

**Тригер**: нова помилка, яку не описано в правилах; користувач виправив агента; та сама проблема вдруге.

1. **Зафіксувати**: що сталося, де, чому не було спіймано (1–3 речення).
2. **Першопричина**: `systematic-debugging` + `root-cause-tracing` — не лікувати симптом.
3. **Кодифікувати**: якщо правило — у профільний `.agents/rules/*.md` (<12 000 символів; інакше новий файл); якщо процедура — оновити/створити підскіл через `skill-creator` + `writing-skills`, додати symlink у `.claude/skills/`.
4. **Закріпити тестом**: Jest/Playwright, що падає без виправлення (RED→GREEN).
5. **Синхронізувати**: рядок у матриці `agents_frontend/backend/review.md` та `.agents/AGENTS.md`; запис у `plans/completed/` або wiki.
6. **Доповісти** користувачу одним рядком: «додано інваріант X у Y».

Не створювати дубль: спершу `grep` по `.agents/` чи вже є таке правило.
