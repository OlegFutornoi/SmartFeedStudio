# SmartFeed Studio — Task Router

Єдина точка входу: визначає **хто** виконує задачу, **які** скіли/референси читати і **що не читати**. Мета — нуль зайвих токенів і нуль пропущених інваріантів.

## Загальні принципи

1. **Мінімальний набір**: ніколи не вантажити всі 75 підскілів. Обрати агента → прочитати лише рядки його матриці, що збігаються з тригером задачі.
2. **Спочатку карта, потім код**: перед пошуком по репозиторію читати `wiki/README.md` та відповідний `wiki/0X-*` розділ; код — через `grep`/outline і діапазони рядків, не файли цілком.
3. **Інваріанти перед кодом**: виписати бізнес-інваріанти задачі (каскади, лічильники, квоти, mock↔real паритет, `@/` імпорти, i18n UA/EN) і після коду перевірити кожен.
4. **Нова проблема = нове знання**: якщо знайдено клас помилки, якого немає в правилах — виконати Self-Evolution (див. референс).
5. **Не комітити** без явної команди користувача.

## Заборони

- Не пропускати Router для «простих» задач — саме вони ховають каскади та паритет.
- Не читати файли цілком, якщо досить діапазону чи `grep`.
- Не оголошувати «готово» без свіжого виводу `tsc --noEmit` і тестів (`verification-before-completion`).
