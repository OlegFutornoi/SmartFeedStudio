# Parser Fuzzing Checklist — Крайові випадки для парсерів фідів

## 1. Специфікації XML/CSV у SmartFeed Studio

Під час імпорту фідів постачальників (Brain, MMM, Websklad) парсери зобов'язані проходити наступні фаззінг-тести:

- [ ] **Неекрановані амперсанди (`&`)**: Назви на кшталт `Dolce & Gabbana` або `H&M` без `&amp;` не повинні валити весь XML стрім.
- [ ] **Вкладені CDATA секції**: Описи товарів з HTML розміткою всередині `<![CDATA[ ... ]]>`.
- [ ] **Змішані закінчення рядків (CRLF vs LF)**: RFC 4180 вимагає CRLF, але багато постачальників віддають звичайний `\n`.
- [ ] **Коми та лапки всередині значень CSV**: `123,"Монітор 27"", 144Hz",4500.00`.
- [ ] **Порожні або відсутні обов'язкові поля**: Товар без ціни, категорії або артикулу повинен безпечно відхилятися або маркуватися чернеткою, не перериваючи імпорт решти 50,000 товарів.
- [ ] **Плаваючий формат десяткових чисел**: `1 450,50` грн vs `1450.50` vs `1450` — коректне парсення локалізованих цін.
