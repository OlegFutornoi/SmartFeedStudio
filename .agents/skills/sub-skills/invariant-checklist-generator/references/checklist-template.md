# Checklist Template — Шаблон інваріантів задачі

Перед початком задачі агент фіксує у робочій нотатці або у `plans/active/<task>.state.md`:

```markdown
### 🛡️ Інваріанти задачі (Task Invariants)

- [ ] **INV-1 (Каскадність)**: Видалення [Батька] тягне за собою видалення всіх [Дітей] (нуль осиротілих рядків у БД чи SQLite).
- [ ] **INV-2 (Агрегати/Лічильники)**: Поле `count` зменшується/збільшується атомарно, без розходжень після оновлення сторінки.
- [ ] **INV-3 (Паритет середовищ)**: Поведінка в браузерному Mock режимі та з реальним NestJS сервером є на 100% ідентичною.
- [ ] **INV-4 (Чистота даних)**: У колонках таблиць відображаються реальні назви (напр. "Brain"), а не назви колонок ("Постачальник").
- [ ] **INV-5 (Коди помилок та i18n)**: Усі можливі збої мають локалізоване повідомлення в `uk` та `en`.
- [ ] **INV-6 (Архітектура та імпорти)**: 100% імпортів через `@/` або `@smartfeed/shared`, нуль `../`, розмір файлу <300 рядків.
```
