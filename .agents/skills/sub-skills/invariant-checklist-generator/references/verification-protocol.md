# Verification Protocol — Протокол верифікації інваріантів

## Етапи перевірки перед здачею задачі

1. **Звірка з чеклистом**: Пройтись по кожному `INV-N`, сформульованому на старті.
2. **Збір фактів (Evidence-Based)**:
   - Для каскадності: запуск тесту з підрахунком записів до і після (`expect(count).toBe(0)`).
   - Для лічильників: перевірка, що лічильник на UI дорівнює кількості рядків у таблиці.
   - Для імпортів: запуск ESLint перевірки на `no-restricted-imports`.
   - Для типів: `pnpm --filter <pkg> exec tsc --noEmit`.
3. **Фіксація результатів**: Відмітити галочками `[x]` всі перевірені інваріанти у звіті користувачу.
