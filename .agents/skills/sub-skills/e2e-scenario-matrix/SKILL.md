# E2E Scenario Matrix

Матриця повного тестового покриття, що унеможливлює формальні "smoke-only" тести.

## Загальні принципи

1. **4D Матриця перевірок**: Кожна нова або змінена сутність тестується на перетині:
   - **Сутність** (Товари, Фіди, Постачальники, Категорії, Ліцензії, Користувачі)
   - **Операція** (Створення, Фільтрація, Редагування, Каскадне видалення, Імпорт)
   - **Режим** (Mock/SQLite ⇄ Real Backend API)
   - **Мова** (Українська ⇄ English)
2. **Перевірка бізнес-інваріантів**: Тест обов'язково перевіряє конкретні дані, оновлення лічильників та каскадне очищення.
3. **Заборона порожніх тестів**: `expect(page).toBeDefined()` або перевірка лише наявності контейнера таблиці без перевірки рядків і значень — вважається браком.

## Заборони

- Не випускати фічу без тестів обох мов (UA ⇄ EN).
- Не випускати фічу видалення без тесту на каскадне зменшення лічильників та видалення зв'язаних сутностей.
