# Matrix Template — 4D Матриця сценаріїв тестування

Кожна сутність розгортається за такою матрицею:

| Операція            | Mock/SQLite (UA)                              | Mock/SQLite (EN)                          | Real Backend (UA)                    | Real Backend (EN)                     |
| ------------------- | --------------------------------------------- | ----------------------------------------- | ------------------------------------ | ------------------------------------- |
| **Create / Import** | Перевірка додавання + перерахунок лічильників | Перевірка форми та тостів англійською     | Створення через API, збереження в PG | i18n заголовки та повідомлення успіху |
| **Read / Filter**   | Фільтрація локальних даних, пошук             | Локалізовані плейсхолдери та бейджі       | Пагінація, сортування, 0 N+1 запитів | Перевірка назв колонок та статусів    |
| **Update / Edit**   | Редагування полів, реактивність UI            | Валідаційні повідомлення форми EN         | Мутація в БД, оновлення версії       | Модалка підтвердження англійською     |
| **Cascade Delete**  | Видалення сутності -> видалення зв'язаних     | Діалог видалення EN, перевірка лічильника | `ON DELETE CASCADE` у PostgreSQL     | Зменшення `totalProducts` у відповіді |
| **Network Error**   | Симуляція помилки збереження -> тост          | Локалізований текст помилки EN            | Обрив зв'язку, збереження стану в UI | Локалізований текст помилки UA        |
