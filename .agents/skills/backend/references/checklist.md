# 📋 Backend Quality & Pre-Commit Checklist

Detailed verification checklist for every backend change in `services/backend-api` and `@smartfeed/shared`.

---

## 1. 🏛 Architecture & CQRS Integrity

- [ ] **Module Boundaries**: `UsersModule` handles only DB persistence via Prisma. No auth, JWT, or token logic inside `UsersModule`.
- [ ] **Bus Communication**: `AuthModule` uses `CommandBus` (`CreateUserCommand`) and `QueryBus` (`GetUserByEmailQuery`).
- [ ] **Event-Driven Side Effects**: Asynchronous side effects (license provisioning, emails, audit logs) listen to events via `EventBus`.
- [ ] **Asynchronous Processing**: Heavy parsing, feed exports, and background sync use BullMQ queues, never blocking HTTP threads.
- [ ] **S3 Streaming Protection**: File uploads/downloads use Presigned URLs generated by `StorageModule`. Server RAM is never burdened with multi-MB buffers.

---

## 2. 🛡 4-Layer Defense-in-Depth Validation

- [ ] **Layer 1 (DTO)**: All DTO properties decorated with `class-validator` (`@IsString()`, `@IsEnum()`, `@IsOptional()`, `@IsInt()`, etc.). `ValidationPipe` configured with `whitelist: true, forbidNonWhitelisted: true`.
- [ ] **Layer 2 (Domain/Quota)**: Invariant checks (quota limits, subscription validity, license status) executed inside Command/Query Handlers.
- [ ] **Layer 3 (Guards & RBAC)**: Endpoints protected by `@UseGuards(JwtAuthGuard, RequireActiveLicenseGuard, RolesGuard)`.
- [ ] **Layer 4 (Database Constraints)**: Foreign keys with appropriate `ON DELETE CASCADE/RESTRICT`, unique constraints, atomic transactions.

---

## 3. 🐘 PostgreSQL & Prisma Rules

- [ ] **Foreign Key Indexes**: Every FK column has an explicit `@@index([fkColumn])` in `schema.prisma`.
- [ ] **Naming Conventions**: All models use `@@map("snake_case_table")` and columns use `@map("snake_case_column")`.
- [ ] **Timestamps**: All timestamps mapped to `timestamptz`.
- [ ] **No OFFSET Pagination**: Feeds, products, and high-volume lists use cursor pagination (`WHERE createdAt < cursor LIMIT N`).
- [ ] **Zero N+1 Queries**: Relational fetching uses `findMany({ where: { id: { in: ids } } })` or `include`.
- [ ] **Connection Pooling**: `PrismaService` utilizes `@prisma/adapter-pg` with `pg.Pool`.
- [ ] **Short Transactions**: `$transaction()` never wraps external network/HTTP calls.
- [ ] **GIN Search Indexes**: Free-text search on names/emails uses `gin_trgm_ops` GIN indexes.

---

## 4. 🔒 Security & Code Cleanliness

- [ ] **Zero Command Injection (CWE-78)**: Never use `exec` with string concatenation. Use `execFile(bin, args, { shell: false })`.
- [ ] **Zero Silent Failures**: No empty `catch {}` blocks. Always log structured context or rethrow a domain exception.
- [ ] **Zero `as any` Bypasses**: Strict typing with `@smartfeed/shared` interfaces, Zod schemas, or explicit type guards.
- [ ] **Password Security**: Passwords hashed using Argon2id or bcrypt with appropriate salt rounds.
- [ ] **Component Modularity Budget**: Every file is kept under **250–300 lines**.

---

## 5. 🌐 REST API Design & OpenAPI Standards

- [ ] **REST Conventions**: Plural nouns, lowercase kebab-case paths (`/api/catalogs`, `/api/tariff-plans`).
- [ ] **Single Canonical Endpoint**: Exactly 1 endpoint per business process (e.g. `change-password` strictly in `AuthController`).
- [ ] **HTTP Status Codes**: `200` (OK), `201` (Created), `400` (Validation), `401` (Auth), `403` (Quota/Role), `404` (Not Found), `409` (Conflict), `429` (Rate limit).
- [ ] **Swagger/OpenAPI Complete**: Controllers annotated with `@ApiTags()`, `@ApiOperation()`, `@ApiResponse()`, `@ApiBearerAuth()`; DTOs annotated with `@ApiProperty()`.
- [ ] **Zero Secret Leaks**: Passwords, hashes, and internal tokens stripped via response DTO mappers or `@Exclude()`.
- [ ] **Rate Limiting**: `ThrottlerGuard` active on public authentication and recovery endpoints.
- [ ] **Tenant Scoping**: User tenant extracted from `@CurrentUser()`, never trusted from unchecked payload.

---

## 6. 🧪 Testing & Teardown Policy

- [ ] **TDD Followed**: Failing test written and verified (RED) before production code was written (GREEN).
- [ ] **Zero Mock Behavior Testing**: Tests verify real functionality with test database, not mock existence.
- [ ] **Teardown Active**: Centralized `cleanDatabase(prisma)` called in BOTH `beforeAll` and `afterAll`.
- [ ] **Teardown Hierarchy**:
  1. `Snapshot` & `ProductImage`
  2. `OrganizationInvitation`
  3. `OrganizationMember`
  4. `License`
  5. `Organization`
  6. `User`
  7. `TariffPlan` & `NavigationItem`
- [ ] **No Arbitrary Sleeps**: Tests use condition-based waiting instead of hardcoded timeouts.
