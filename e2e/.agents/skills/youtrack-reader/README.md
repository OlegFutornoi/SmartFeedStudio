# YouTrack Reader & Requirements Extractor (`youtrack-reader`)

Скіл для автоматичного вивантаження, аналізу та вилучення вимог і критеріїв приймання (Acceptance Criteria) із задач YouTrack (`https://youtrack.treeum.net`).

Працює через Playwright із збереженням авторизаційної сесії (`storageState`), що дозволяє один раз увійти через браузер і надалі вивантажувати задачі повністю у фоновому режимі (Headless) без ручного копіювання тексту.

---

## 💬 1. Як користуватися через чат з агентом

Достатньо надіслати агенту номер або посилання на задачу:

- _"Вивчи задачу INSDEV-4750"_
- _"Подивись опис задачі https://youtrack.treeum.net/issue/TMS-894"_
- _"Зроби тест-план за задачею SUP-3333"_

Агент автоматично запустить скіл, прочитає вміст задачі і складе тест-план.

---

## 🔐 2. Перший вхід (Авторизація через браузер)

Перед першим використанням або коли сесія завершилась, запустіть скрипт авторизації:

```bash
node .agents/skills/youtrack-reader/scripts/login.cjs
```

Або одразу із цільовим посиланням:

```bash
node .agents/skills/youtrack-reader/scripts/login.cjs https://youtrack.treeum.net/issue/INSDEV-4750
```

1. Відкриється вікно браузера із формою входу YouTrack.
2. Виконайте вхід під своїм корпоративним обліковим записом (SSO / Google / логін і пароль).
3. Після завантаження інтерфейсу YouTrack поверніться в термінал і натисніть **Enter** (або скрипт зафіксує вхід автоматично).
4. Сесія збережеться у `.playwright-cli/youtrack-state.json`.

---

## 💻 3. Запуск вивантаження вручну (CLI)

```bash
# За ідентифікатором задачі
node .agents/skills/youtrack-reader/scripts/fetch-task.cjs INSDEV-4750

# За повним посиланням
node .agents/skills/youtrack-reader/scripts/fetch-task.cjs https://youtrack.treeum.net/issue/INSDEV-4750
```

Результати зберігаються у директорію `.temp/`:

- `.temp/youtrack-issue.md` — форматований Markdown для читання людиною та ШІ.
- `.temp/youtrack-issue.json` — структурований JSON з усіма атрибутами.

---

## 📋 4. Які дані витягує скіл

- **Ідентифікатор та Заголовок:** `ID`, `Summary`.
- **Поля задачі:** Стан (`State`), Пріоритет (`Priority`), Виконавець (`Assignee`), Підсистема (`Subsystem`), Тип (`Type`), Спринт тощо.
- **Повний опис:** Текст опису, таблиці, чеклісти, Acceptance Criteria.
- **Вкладення:** Посилання на скріншоти, мокапи, специфікації.
- **Коментарі:** Останні обговорення розробників та QA.

---

## 🛡️ 5. Безпека даних

- Файл сесії `.playwright-cli/youtrack-state.json` знаходиться у списку `.gitignore`. Ваші облікові дані та сесійні cookies ніколи не потраплять у репозиторій Git.
