# ⚡ SmartFeed Studio — Команди Агентів (Agent Slash Commands)

> **Розташування:** `.agents/commands/` (дзеркало в `.claude/commands/`)  
> **Формат:** TOML специфікації команд для Claude Code, Antigravity IDE та сумісних агентських CLI.

Цей каталог містить автоматизовані робочі процеси та команди розробки (інтегровані з пайплайну розробки Addy Osmani). Кожна команда пов'язує спеціалізовані скіли у покроковий алгоритм дій.

---

## 🚀 Як запускати команди

1. **У чаті Antigravity IDE / Claude Code:**
   - Введіть назву команди в повідомленні, наприклад:
     ```text
     /build auto
     ```
     або
     ```text
     /code-simplify apps/desktop/src/modules/products/ProductsTable.tsx
     ```
2. **Через прямий виклик агента:**
   - Можна написати звичайним текстом:
     ```text
     виконай /review для останніх змін у бекенді
     ```
