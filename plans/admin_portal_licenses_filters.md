# 📋 План: Розширена Фільтрація та Вибірки в Таблиці Ліцензій (shadcn Data Table Patterns)

> **Статус:** ✅ **Реалізовано та протестовано (100% тестів пройдено)**  
> **Дата виконання:** 27.08.2026

> **Мета:** Впровадити сучасну систему фільтрації та швидких вибірок на сторінці `/licenses` в Admin Portal за патернами **shadcn/ui Data Table Toolbar & Faceted Filters**, що дозволить адміністраторам миттєво знаходити ліцензії за ключем, користувачем, тарифом, статусом активності, наявністю хмарного бекапу та сортувати за квотами.

---

## 🔍 1. Аналіз Рішень та Компонентів shadcn/ui

У екосистемі **shadcn/ui Data Table** найкращим стандартом є комбінація:

1. **`DataTableToolbar`**: Горизонтальна панель інструментів із пошуковим інпутом, фасетними фільтрами, перемикачами та кнопкою скидання.
2. **`DataTableFacetedFilter`**: Фільтр за категоріями з бейджами кількості для кожного варіанта (наприклад: `PRO [3]`, `STARTER [12]`).
3. **`DataTableViewOptions` / Sort**: Швидке сортування за квотами XML, AI-кредитами, датою закінчення.
4. **`ActiveFiltersPills`**: Інтерактивні плашки активних фільтрів із кнопкою швидкого видалення `X`.

## 🏛 2. Архітектура та Декомпозиція Компонентів

Для дотримання правила **Single Responsibility & Component Modularity (max ~250–300 рядків)** структура буде декомпонована на окремі модулі:

```text
apps/admin-portal/src/components/plans/
├── LicensesTable.tsx                 # Головний контейнер таблиці ліцензій
├── LicensesTableToolbar.tsx          # [НОВИЙ] Панель фільтрів, пошуку та сортування
├── LicensesFacetedFilter.tsx         # [НОВИЙ] Фасетний селектор фільтрів з бейджами кількості
└── LicensesActiveFilters.tsx         # [НОВИЙ] Плашки активних фільтрів і лічильник результатів
```

## ⚙️ 3. Функціонал Фільтрації та Вибірок

### 3.1. Текстовий пошук (Search Input)

- Миттєвий пошук з іконкою `Search` та очищенням `X`.
- Пошук здійснюється одночасно за:
  - **Ліцензійним ключем** (наприклад, `SF-PRO-`, `SF-FREE-`)
  - **ПІБ клієнта** (наприклад, `Олег`, `Admin`)
  - **Email адресою** (наприклад, `admin@gmail.com`)

### 3.2. Фасетний фільтр за Тарифним Планом (Plan Tier Filter)

- Варіанти:
  - `Всі тарифи` (із загальною кількістю)
  - `STARTER` (з бейджем кількості)
  - `GROWTH` (з бейджем кількості)
  - `PRO` (з бейджем кількості)
  - `ENTERPRISE` (з бейджем кількості)
  - Будь-які кастомні тарифи з бази даних

### 3.3. Фільтр за Статусом Дії (Validity / Expiry Filter)

- `Всі статуси`
- `🟢 Активні` (не прострочені та `isActive: true`)
- `🔴 Закінчилися` (термін дії минув)
- `♾️ Безстрокові` (`expiresAt === null`)

### 3.4. Фільтр за Хмарним Бекапом (Cloud Backup S3)

- `Всі`
- `☁️ З S3 Бекапом` (`canCloudBackup === true`)
- `— Без бекапу` (`canCloudBackup === false`)

### 3.5. Сортування (Sorting)

- `Найновіші спочатку` (за датою створення або ID)
- `Термін дії (найближчі спочатку)`
- `Ліміт товарів XML (від більшого до меншого)`
- `AI Кредити (від більшого до меншого)`

### 3.6. Бейджі активних фільтрів та Кнопка Скидання (Reset Filters)

- Відображення активних критеріїв: `[Тариф: PRO ✕]`, `[Статус: Активні ✕]`, `[S3 Бекап ✕]`.
- Кнопка **«Скинути фільтри»** з іконкою `RotateCcw` / `X`, яка з'являється тільки за наявності активних фільтрів.
- Індикатор кількості знайденого: `Показано 3 з 15 ліцензій`.

### 3.7. Порожній Стан (Empty State)

- Якщо за заданою комбінацією фільтрів нічого не знайдено:
  - Відображається інформативна картка: `«Жодної ліцензії за обраними фільтрами не знайдено»`.
  - Кнопка швидкого скидання `«Очистити всі фільтри»`.

## 🧪 5. План Автоматизованого Тестування (Playwright POM)

У `apps/admin-portal/e2e/licenses.spec.ts` та `apps/admin-portal/e2e/pages/licenses.page.ts`:

1. `should filter licenses by search query (key, email, name)` — перевірка миттєвої фільтрації за текстом.
2. `should filter licenses by plan tier and update results count` — перевірка вибірки за тарифом (наприклад, тільки `PRO` або `STARTER`).
3. `should filter licenses by cloud backup availability` — вибірка ліцензій з увімкненим S3 бекапом.
4. `should reset all filters when clicking clear button` — перевірка повернення повного списку при скиданні.
