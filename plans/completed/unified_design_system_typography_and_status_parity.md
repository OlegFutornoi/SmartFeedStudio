## 🔍 1. Інженерний аудит поточного стану (`agents_review`)

На основі аналізу скріншотів користувача та кодової бази (`apps/admin-portal` та `apps/desktop`) зафіксовано 4 критичні групи невідповідностей:

### 1. Розсинхрон клієнтських колонок (Клієнт з фото vs без фото):

- **Дашборд (таб `Користувачі`)**: рендерить `<Avatar className="h-6 w-6">` з кольоровими ініціалами `[ОЛ]` та ім'ям `Олег`.
- **Дашборд (таб `Останні транзакції`)**: рендерить **голий текстовий `<span>` без аватарки** (`Олег`).
- **Дашборд (таб `Ліцензії`)**: рендерить **голий текстовий `<span>` без аватарки** (`Олег`).
- **Сторінка `/transactions`**: рендерить ім'я та email у два рядки, але **повністю без аватарки**.
- **Сторінка `/licenses`**: рендерить ім'я та email у два рядки, але **повністю без аватарки**.
- **Сторінка `/users`**: використовує кастомний інлайн `div size-7` замість стандартизованого компонента.
- **Корінна причина**: відсутність єдиного універсального компонента `UserAvatarCell`.

### 2. Розсинхрон статусних кольорів («Тут зелений, а тут ні»):

- **Дашборд (транзакції)**: статус `APPROVED` має зелений колір (`bg-emerald-500/10 text-emerald-600 border-emerald-500/20` з крапкою `bg-emerald-500`).
- **Дашборд (ліцензії)**: статус `Active` має зелений колір.
- **Дашборд (користувачі)**: статус `Done` має зелений колір.
- **Сторінка `/transactions`**: успішний статус `Оплачено` рендерився як `bg-primary/10 text-primary border-primary/20` (сірий/темний колір теми primary, **НЕ зелений!**).
- **Сторінка `/users`**: активний статус рендериться як `bg-primary/10 text-primary border-primary/20` (**НЕ зелений!**).
- **Сторінка `/licenses`**: активний статус рендериться як `border-border text-foreground` без фонового кольору (**НЕ зелений!**).
- **Корінна причина**: кожна сторінка імплементувала свій статусний бейдж ізольовано без єдиного токена успіху `emerald`.

### 3. Англомовні сирі статуси в українському інтерфейсі:

- **Дашборд (транзакції)**: виводився сирий енум бази даних `APPROVED` капсом англійською замість локалізованого `Оплачено`.
- **Дашборд (ліцензії)**: виводився сирий англійський рядок `Active` / `Suspended` замість `Активна` / `Призупинена`.
- **Дашборд (користувачі)**: захардкоджений англійський текст `Done` замість статусу користувача.
- **Корінна причина**: пропущені виклики `t()` у табах `DashboardTransactionsTableTab` та `DashboardLicensesTableTab`.

### 4. Хаотична типографіка та відсутність системи для майбутніх налаштувань:

- Понад 100 компонентів використовували хардкодні класи `text-[10px]`, `text-[11px]`, `text-xs`, `text-sm`.
- На дашборді референси та суми мали розмір `text-sm font-semibold`, тоді як у повнорозмірних таблицях — `text-xs`.
- **Проблема для майбутнього функціоналу**: Якщо користувач захоче однією кнопкою в налаштуваннях змінити шрифт або жирність по всьому кабінету, це не спрацює, оскільки розміри та шрифти вбиті статичними класами Tailwind без єдиних CSS-змінних.

### 2. Канонічний статусний бейдж: `StatusBadge`

Створено єдиний компонент `@/components/ui/status-badge.tsx` (в обох додатках):

```tsx
type StatusVariant = 'success' | 'warning' | 'destructive' | 'muted';

interface StatusBadgeProps {
  status: string; // 'APPROVED' | 'ACTIVE' | 'PENDING' | 'DECLINED' | 'SUSPENDED' тощо
  variant?: StatusVariant; // обчислюється автоматично, якщо не задано
  label?: string; // автоматично локалізується через i18n
  isUk?: boolean;
  testId?: string;
}
```

**Семантичні палітри:**

- **`success` (зелений — СУВОРО ОДНАКОВИЙ НА ВСІХ СТОРІНКАХ)**:
  `bg-emerald-500/10 text-emerald-600 dark:text-emerald-400 border-emerald-500/20` з крапкою `bg-emerald-500`.
  Застосовується для: `APPROVED` (Оплачено), `ACTIVE` (Активна/Активний), `SUCCESS` (Синхронізовано), `DONE` (Виконано).
- **`warning` (бурштиновий)**:
  `bg-amber-500/10 text-amber-600 dark:text-amber-400 border-amber-500/20` з крапкою `bg-amber-500`.
  Застосовується для: `PENDING` (В очікуванні), `SYNCING` (Синхронізація).
- **`destructive` (червоний)**:
  `bg-destructive/10 text-destructive border-destructive/20` з крапкою `bg-destructive`.
  Застосовується для: `DECLINED` (Відхилено), `EXPIRED` (Закінчилася), `ERROR` (Помилка).
- **`muted` (нейтральний)**:
  `bg-muted/50 text-muted-foreground border-border`.
  Застосовується для: `SUSPENDED` (Призупинена), `DRAFT` (Чернетка).

### 3. Базові токени типографіки для динамічного масштабування шрифтів:

У `globals.css` та `index.css` введено семантичні змінні:

```css
:root {
  --text-table-header: 0.75rem; /* 12px */
  --text-table-cell: 0.75rem; /* 12px */
  --text-table-sub: 0.6875rem; /* 11px */
  --text-badge: 0.625rem; /* 10px */
}
```

І класи в `@layer utilities`:

- `.text-table-cell`: `text-[length:var(--text-table-cell)]`
- `.text-table-sub`: `text-[length:var(--text-table-sub)]`
- `.text-table-badge`: `text-[length:var(--text-badge)]`
- `.text-table-header`: `text-[length:var(--text-table-header)]`

Це забезпечує повну готовність системи до майбутнього перемикача користувача (наприклад, `data-font-size="sm|md|lg"` або вибір іншого сімейства шрифтів), який в 1 клік оновить усі таблиці та дашборди!
