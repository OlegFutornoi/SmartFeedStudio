## 🔍 1. Аналіз проблеми та кращих практик індустрії

### Причина початкової невідповідності (Root Cause)

1. В `apps/desktop/src/index.css` токен `--radius` був встановлений у `0.15rem` (~2.4px).
2. Базовий компонент `Button` використовує `rounded-md`, який розраховувався як `calc(var(--radius) - 2px) = 0.4px` — тобто візуально абсолютно гострий прямокутник.
3. Компонент `Card` використовує `rounded-xl`, а поле пошуку в Header — `rounded-xl`. Оскільки клас `xl` не був переозначений у `tailwind.config.ts`, Tailwind застосовував свій дефолтний `0.75rem` (12px).
4. **Результат:** на одному екрані сусідили гостра прямокутна кнопка (0.4px) та круглі картки/пошук (12px).

## 🏛 2. Архітектурне рішення: Глобальний дизайн-токен

Щоб не шукати класи по всьому проекту, впроваджено **мультиплікативне масштабування** в `tailwind.config.ts`:

```typescript
borderRadius: {
  none: '0px',
  sm: 'calc(var(--radius) * 0.625)', // 5px при 8px, 0px при 0
  DEFAULT: 'calc(var(--radius) * 0.75)',
  md: 'calc(var(--radius) * 0.75)',   // 6px при 8px, 0px при 0
  lg: 'var(--radius)',                // 8px при 8px, 0px при 0
  xl: 'calc(var(--radius) * 1.5)',    // 12px при 8px, 0px при 0
  '2xl': 'calc(var(--radius) * 2)',   // 16px при 8px, 0px при 0
  '3xl': 'calc(var(--radius) * 3)',   // 24px при 8px, 0px при 0
}
```

### Чому мультиплікативне правило ідеальне?

- Якщо обрано `--radius: 0px` — **АБСОЛЮТНО ВСІ** кнопки, інпути, бейджі, картки, діалоги стають **0px (100% прямокутними)**.
- Якщо обрано `--radius: 0.5rem` (8px) — весь інтерфейс стає гармонійно та концентрично заокругленим (кнопки 6px, картки 12px, модалки 16px).
- Жодного хардкоду в десятках компонентів.
