## 🧭 1. Гібридна Модель Роботи з Фотографіями

Система підтримує два повноцінних сценарії роботи, що дозволяє користувачеві працювати як у безкоштовному автономному режимі, так і в корпоративному режимі з хмарним бекапом.

```mermaid
graph TD
    IMG_IN["🔗 Вхідне посилання на фото з фіду<br/>(напр. https://supplier.com/images/item-123.jpg)"]

    Check_S3{"Підключено хмару S3 / MinIO<br/>(Тариф з canCloudBackup = true)?"}

    subgraph Mode_S3 ["Сценарій А: Хмарний S3 / MinIO Пайплайн"]
        S3_Q["📦 Фонова черга BullMQ (image-downloader)"]
        S3_Proc["✂️ Sharp: оптимізація у WebP, 3 розміри:<br/>• Thumb: 150x150<br/>• Medium: 600x600<br/>• Full: Original"]
        S3_Up["🪣 Завантаження в S3 Bucket / Cloudflare R2"]
        S3_URL["⚡ Швидкий CDN URL (smartfeed.cdn/.../item-123.webp)"]
    end

    subgraph Mode_Local ["Сценарій Б: Без S3 / Прямі посилання + Локальний кеш"]
        Direct_Show["🌐 Пряме завантаження з CDN постачальника в браузері"]
        Desktop_Cache["💻 Desktop Cache: збереження у локальний кеш (AppData/cache/images)"]
        Fallback_Img["🛡️ Fallback: Плейсхолдер при битому посиланні (404/Timeout)"]
    end

    IMG_IN --> Check_S3
    Check_S3 -->|ТАК (Pro / Enterprise)| S3_Q --> S3_Proc --> S3_Up --> S3_URL
    Check_S3 -->|НІ (Starter / Free / Offline)| Direct_Show --> Desktop_Cache
    Direct_Show -->|Помилка завантаження| Fallback_Img
```

## 🪣 2. Сценарій А: Хмарне сховище S3 / MinIO (Cloud Mode)

Коли у користувача активний тариф з підтримкою S3 (або підключено власний MinIO/S3 через налаштування):

1. **Фоновий пайплайн обробки (BullMQ Worker)**:
   - Після імпорту товарів фоновий воркер бере нові посилання `originalUrl` з таблиці `ProductImage`.
   - Завантажує оригінальне зображення через HTTP-стрім з таймаутом (5 сек).
2. **Оптимізація та стиснення (`sharp`)**:
   - Конвертація в сучасний легкий формат `WebP` (стиснення на 60–80% без втрати якості).
   - Генерація трьох форматів:
     - **Thumbnail (150x150)**: для швидкого показу в таблиці каталогу (вага ~5-10 KB).
     - **Card Preview (600x600)**: для картки товару та перегляду списку (вага ~30-50 KB).
     - **Full Resolution**: для перегляду з лупою та експорту в маркетплейси.
3. **Збереження ключів у S3**:
   - Шлях: `organizations/{orgId}/catalogs/{catalogId}/products/{productId}/{hash}_{size}.webp`.
   - Збереження посилання в колонку `cloudUrl` та `thumbnailUrl`.

## 💻 3. Сценарій Б: Робота БЕЗ S3 (Direct Links & Desktop Local Cache)

Якщо у користувача немає S3 або він працює в локальному автономному додатку Desktop:

1. **Прямий вивід (`Direct External URL`)**:
   - У таблиці товарів використовується оригінальний `originalUrl` постачальника.
   - Компонент `<ProductImageThumbnail src={product.images[0]?.originalUrl} />` використовує браузерний `loading="lazy"` та `decoding="async"`.
2. **Локальне кешування в Desktop App (Tauri)**:
   - При перегляді товарів десктопний Rust-рушій фоново кешує завантажені фото у внутрішню папку додатку:
     `~/.smartfeed/cache/images/{md5_hash_url}.jpg`.
   - Якщо інтернет пропадає або постачальник блокує часті запити — додаток віддає фото з локального диска через кастомний протокол Tauri `asset://`.
3. **Захист від битих посилань (Error Boundary & Placeholders)**:
   - Якщо постачальник видалив фото (404 Not Found), сервер недоступний або спрацював CORS/Hotlink Protection:
   - Компонент автоматично підставляє елегантний нейтральний SVG-плейсхолдер із назвою товару або іконкою `ImageIcon` та бейджем `«Фото недоступне»`.
   - Товар не ламає верстку таблиці.

## 🎨 4. Інтерфейс Галереї Фото у Картці Товару (Image Gallery UI)

У детальному перегляді та редакторі товару користувач має повний контроль над фотографіями:

1. **Інтерактивна галерея (Thumbnail Strip + Main Preview)**:
   - Головне фото великим планом з можливістю зуму (Hover Zoom / Click to Expand).
   - Нижня смужка мініатюр (Carousel / Strip) з індикатором активного фото.
2. **Drag & Drop сортування**:
   - Зміна порядку фотографій простим перетягуванням мишкою.
   - Перше фото в списку автоматично отримує статус `isMain = true`.
3. **Керування джерелами фото**:
   - **Додати посилання (URL)**: Вставка списку прямих посилань на фото.
   - **Завантажити файл з комп'ютера**: Прямий вибір файлів (JPG, PNG, WebP) з диска.
   - **Видалити / Замінити фото**: Кнопка кошика на кожній мініатюрі.
   - **Масова перевірка валідності**: Кнопка «Перевірити доступність усіх фото» — перевіряє HTTP-статуси всіх URL фіду.
